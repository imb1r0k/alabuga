# Инструкция по запуску Бота ВКонтакте

Данный бот работает в связке с базой данных сайта (MySQL) и управляется полностью из Админ-панели портала (раздел "Бот ВК").

## Шаги по запуску:

1. **Заполните параметры в Админ-панели:**
   - Перейдите в админ-панели в раздел **"Бот ВК"** -> **"Настройки бота и Тексты"**.
   - Укажите **VK Token** (Ключ доступа сообщества) и **ID Сообщества**.

2. **Установите Python зависимости:**
   ```bash
   cd vk_bot
   pip install -r requirements.txt
   ```

3. **Запустите бота:**
   ```bash
   python bot.py
   ```

Бот автоматически подтянет все созданные в админке волны заданий, отсортирует квесты по сложности, будет отправлять ссылки/скриншоты на проверку и генерировать лотерейные билеты!
