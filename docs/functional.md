# Функциональное описание портала и бота ВК

## 1. Общее описание

Портал предназначен для организации проживания участников форума, работы команд, выдачи заданий через бота ВКонтакте и управления лотерейными билетами. Система состоит из:

- **Веб-приложение** (React + TypeScript) — личный кабинет, админ-панель, публичные страницы.
- **PHP REST API** — серверная логика, работа с базой данных MySQL.
- **Python-бот ВКонтакте** — выдача заданий, приём отчётов, отправка уведомлений, обработка заявок.

## 2. Роли и права доступа

| Роль | Обозначение | Права |
|------|-------------|-------|
| **Пользователь** | `user` | Может просматривать главную страницу, авторизоваться/регистрироваться, выбирать комнату вручную или через автозаселение, видеть свой профиль, свою команду (участников, чат, календарь), свой рейтинг, свои бронирования. Не имеет доступа к админ-панели. |
| **Куратор** | `curator` или `moderator` (в БД `curator`) | Имеет доступ к админ-панели, но только к разделам: «Пользователи» (в рамках своих команд), «Команды» (управление участниками, чат, календарь своей команды), «Бот ВК» (просмотр отчётов, заданий, заявок в рамках своих команд), «Общие настройки» (только просмотр?). В конфигурации `isCurator` позволяет доступ к `/admin-panel` и `/admin-panel/teams`, `/admin-panel/users`, `/admin-panel/vk-bot` (но строгое ограничение на стороне сервера по `getCuratorTeams`). Не может управлять корпусами/этажами/комнатами и бронированиями (только если он не admin). |
| **Администратор** | `admin` | Полный доступ ко всем разделам: статистика, экспорт/очистка, настройки портала, управление пользователями, бронированиями, корпусами/этажами/комнатами, командами, ботом ВК (включая настройки, рассылки, билеты). |

## 3. Функционал веб-сайта

### 3.1. Главная страница (`/`)
- Отображает Hero-блок, настраиваемый в админке (бейдж, заголовок, описание, кнопки).
- Ссылка на авторизацию/регистрацию или в личный кабинет (в зависимости от состояния).
- Присутствует глобальное уведомление (если включено в настройках), которое показывается всем пользователям (тип `permanent`) или один раз (`one-view`).

### 3.2. Авторизация и регистрация (`/auth`)
- Вход по логину/телефону + пароль.
- Регистрация нового пользователя (ФИО, телефон, логин, пароль — можно сгенерировать автоматически).
- При регистрации создаётся токен, пользователь автоматически авторизуется.

### 3.3. Личный кабинет (`/dashboard`)
- Просмотр текущего бронирования (комната, корпус, этаж, статус).
- Возможность отозвать заявку.
- История бронирований.
- Профиль пользователя (био, ссылки на соцсети).
- **Команда**: просмотр состава, чат, календарь событий.
- **Рейтинг**: отображается, если включён в настройках.

### 3.4. Выбор комнаты (`/auto-booking` и ручной выбор)
- Ручной выбор: отображение списка корпусов, этажей, сетки комнат с указанием занятости.
- По клику на свободную комнату открывается модальное окно с информацией о вместимости, занятых местах и кнопкой «Забронировать».
- Автозаселение: пользователь выбирает пол, система автоматически подбирает комнату согласно полу и настройкам автозаселения.
- При бронировании (если пользователь не авторизован) происходит регистрация, токен сохраняется.

### 3.5. Публичный профиль (`/public_profile/:login`)
- Открытая карточка пользователя: ФИО, рейтинг, команда, текущее бронирование, ссылки на соцсети.
- Доступна по прямой ссылке или QR-коду.

## 4. Админ-панель

### 4.1. Общие настройки (`/admin-panel`)
- **Статистика**: количество корпусов, комнат, мест, занятых мест, заявок, пользователей; сводка по статусам бронирований.
- **Экспорт**: выгрузка бронирований, макетов корпусов, пользователей в Excel.
- **Очистка**: архивация всех бронирований, архивация всех пользователей (кроме админов), очистка всех командных чатов (с подтверждением).
- **Настройки портала**: название сайта, hero-блок (текст, кнопки), включение рейтинга, режим автозаселения (по полу или по полу + совпадение ФИО с аккаунтами из VK).
- **Глобальное уведомление**: настройка текста, типа (`permanent` / `one-view`), включение/выключение.

### 4.2. Пользователи (`/admin-panel/users`)
- Список пользователей с поиском, фильтрами (статус, роль, команда).
- Редактирование: ФИО, логин, телефон, роль, статус, команда, рейтинг, пароль.
- Просмотр истории бронирований пользователя.
- Привязка куратора к командам (выбор нескольких или «все команды»).
- Экспорт списка пользователей в Excel.
- Генерация QR-кода на публичный профиль.

### 4.3. Бронирования (`/admin-panel/bookings`)
- Таблица всех бронирований с фильтрами по статусам (скрытие отклонённых, отозванных, архивных).
- Поиск по ФИО, телефону, логину, корпусу, комнате, команде.
- Быстрое изменение статуса прямо из таблицы.
- Модальное окно управления: смена комнаты, статуса, комментария.
- Автоматическое одобрение ботом (включается переключателем) — период проверки 10 секунд.
- Отображение дубликатов по ФИО среди активных заявок.

### 4.4. Корпуса и комнаты (`/admin-panel/buildings`)
- Создание/редактирование/удаление корпусов (имя, пол здания).
- Этажи: номер, ширина сетки, начальный номер комнаты, порядок нумерации (по часовой / сверху вниз), пол этажа.
- Редактор этажа в режиме «редактирование»:
  - Визуальная сетка с комнатами, лестницами, лифтами, техническими помещениями.
  - Drag & drop для перемещения плиток.
  - Заполнение ячейки типом помещения (комната, лифт, лестница, техническое).
  - Редактирование свойств комнаты (номер, название, вместимость, пол).
  - Просмотр бронирований в комнате, изменение статусов заявок.
  - Генерация комнат по маркерам «Начало», «Поворот», «Конец» с автоматической нумерацией.
- Сохранение изменений локально с кнопкой «Сохранить».

### 4.5. Команды (`/admin-panel/teams`)
- Создание/редактирование/удаление команд.
- Управление участниками (добавление/удаление).
- Просмотр командного чата, возможность отправлять сообщения от имени админа, очищать чат, удалять отдельные сообщения.
- Календарь команды: добавление событий с описанием, изображением (загрузка файла или URL), удаление событий.

### 4.6. Бот ВК (`/admin-panel/vk-bot`)
- **Настройки**: VK Token, ID сообщества, ссылка на сайт, приветственный текст, текст успешного выполнения всех заданий, время розыгрыша.
- **Волны заданий**: создание групп заданий с датами начала/окончания; внутри каждой волны создание задач с названием, описанием, сложностью (простое/среднее/сложное — +10/20/30 баллов), типом (репост, пост, другое).
- **Проверка отчётов**: список отчётов от пользователей с прикреплёнными фото/файлами, возможность принять (начислить баллы и выдать билет) или отклонить с указанием причины.
- **Заявки**: список обращений пользователей (категории: сайт, бот, жильё), просмотр переписки, отправка сообщений от админа, изменение статуса.
- **Билеты**: реестр выданных билетов с фильтром по волне.
- **Рассылка**: отправка сообщений от имени бота всем пользователям / активным / обладателям билетов.
- **Статистика** (не выведена в UI, но эндпоинт есть): количество пользователей, отчётов, билетов.

## 5. Функционал бота ВКонтакте

Бот работает на Python, использует LongPoll API. Он:

- Регистрирует пользователей по VK ID (создаёт или связывает аккаунт, отправляет логин/пароль).
- Требует согласия с правилами (один раз).
- Предоставляет главное меню: «Задания», «Мой профиль», «Заявки», «Личный кабинет».
- **Задания**: отображает активную волну с заданиями, сгруппированными по сложности; показывает статус каждого задания (не выполнено / на рассмотрении / выполнено / отклонено).
- При выборе задания показывает описание, баллы, инструкцию. Пользователь отправляет текст/фото/файлы как отчёт.
- **Отчёты** сохраняются в базу, администратор проверяет их в админке. После одобрения начисляются баллы, при выполнении всех заданий волны выдается лотерейный билет (автоматически) и пользователь получает уведомление.
- **Профиль**: показывает рейтинг, количество выполненных заданий, полученные билеты (за последние 30 дней) с указанием волны.
- **Заявки**: пользователь может создать заявку (выбрать категорию, тему, описание), просмотреть свои заявки и общаться в чате по ним (отправка сообщений). Администратор видит заявки в админке и может отвечать.
- **Уведомления**: бот отправляет уведомления о статусе отчётов, ответах по заявкам, рассылках.
